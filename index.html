3 種安裝到安卓手機的方式

方案 1：WebIntoApp 線上轉 APK 免裝開發環境・產出真 APK
  1. 先點上方按鈕下載 index.html，將它壓縮成 app.zip。
  2. 打開免費網站 webintoapp.com，點選「HTML / ZIP」上傳壓縮檔。
  3. 輸入 APP 名稱後點選「Make App」，即可免費下載 .apk 傳到手機安裝。
方案 2：PWA 直接加到手機主畫面 最快 30 秒搞定
  1. 把下載的 index.html 用 LINE 傳到手機。
  2. 用手機 Chrome 瀏覽器打開，點右上角「⋮」→「加到主畫面」即可像原生 APP 一樣全螢幕離線使用。
方案 3：Website 2 APK / Android Studio 電腦本地打包

在電腦使用免費軟體 Website 2 APK Builder（選 Local HTML Website 指向該檔案），或放到 Android Studio 的 assets/index.html 用 WebView 載入即可輸出 APK。
